# API Design Crew

Turns a feature request into a reviewed REST API contract with endpoints and schemas.

```sh
fabri new agency --from gh:Rushour0/fabri-rosters/agencies/api-design-crew my-api-design-crew && fabri serve
```

Installation replaces `__AGENCY_ROOT__` with the agency directory, `__AGENCY_SLUG__` with a unique memory slug, and `__RUN_FROM__` with the caller's working directory.
