# SEO Brief Crew

Builds an SEO content brief with a clear angle, keyword themes, and outline from a target topic.

```sh
fabri new agency --from gh:Rushour0/fabri-rosters/agencies/seo-brief-crew my-seo-brief-crew && fabri serve
```

Installation replaces `__AGENCY_ROOT__` with the agency directory, `__AGENCY_SLUG__` with a unique memory slug, and `__RUN_FROM__` with the caller's working directory.
