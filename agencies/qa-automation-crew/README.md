# QA Automation Crew

Generates and runs a focused test suite for a target module.

```sh
fabri new agency --from gh:Rushour0/fabri-rosters/agencies/qa-automation-crew my-qa-crew && fabri serve
```

Installation replaces `__AGENCY_ROOT__` with the agency directory, `__AGENCY_SLUG__` with a unique memory slug, and `__RUN_FROM__` with the caller's working directory.
