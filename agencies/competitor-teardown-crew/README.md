# Competitor Teardown Crew

Turns competitor materials into a concise, evidence-led teardown. The crew maps the rival's positioning and feature set, then surfaces its pricing posture and differentiation gaps.

Deliverable: A structured competitor teardown: positioning, key features, pricing, and the gaps to exploit.

```sh
fabri new agency --from gh:Rushour0/fabri-rosters/agencies/competitor-teardown-crew competitor-teardown-crew
```

At install time, `__AGENCY_ROOT__` becomes this agency directory, `__AGENCY_SLUG__` makes its memory collections unique, and `__RUN_FROM__` resolves the caller's working directory for the SQLite memory database.
