# Sales Outreach Crew

Researches a supplied lead profile and drafts a personalized three-touch outreach sequence.

```sh
fabri new agency --from gh:Rushour0/fabri-rosters/agencies/sales-outreach-crew my-outreach-crew && fabri serve
```

Installation replaces `__AGENCY_ROOT__` with the agency directory, `__AGENCY_SLUG__` with a unique memory slug, and `__RUN_FROM__` with the caller's working directory.
