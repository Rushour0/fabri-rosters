# Incident Postmortem Crew

Converts a raw incident timeline into a factual, blameless postmortem with action items.

```sh
fabri new agency --from gh:Rushour0/fabri-rosters/agencies/incident-postmortem-crew my-postmortem-crew && fabri serve
```

Installation replaces `__AGENCY_ROOT__` with the agency directory, `__AGENCY_SLUG__` with a unique memory slug, and `__RUN_FROM__` with the caller's working directory.
