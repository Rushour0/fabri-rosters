# Data Analysis Crew

Inspects a supplied dataset and produces an evidence-based findings brief.

```sh
fabri new agency --from gh:Rushour0/fabri-rosters/agencies/data-analysis-crew my-data-analysis-crew && fabri serve
```

Installation replaces `__AGENCY_ROOT__` with the agency directory, `__AGENCY_SLUG__` with a unique memory slug, and `__RUN_FROM__` with the caller's working directory.
